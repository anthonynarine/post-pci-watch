# Post-PCI Watch

Post-PCI Watch is an educational remote-monitoring application that simulates wearable data for a hypothetical patient following percutaneous coronary intervention (PCI).

The project demonstrates how Next.js, Clerk, and Convex can support an authenticated, real-time clinical workflow. Synthetic measurements flow into a reactive clinician dashboard, deterministic rules identify noteworthy events, and an eventual AI layer produces grounded summaries for human review.

This is a learning and portfolio project. It uses synthetic data only and is not intended to provide medical advice, diagnosis, or patient care.
